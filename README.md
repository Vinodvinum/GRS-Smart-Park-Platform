# GRS Smart Park Platform

Cumulative portfolio-grade full-stack project built through ZIP 01–ZIP 10.

## Start
1. Install Node dependencies.
2. Configure environment variables from `.env.example` if present.
3. Start the local database when required.
4. Generate Prisma client.
5. Run migrations/seed.
6. Start the Next.js development server.
